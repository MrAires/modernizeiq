# React Modernization Workbench — planned component

This directory records the future interface contract. There is no React application here yet. The first-task deliverable is the deterministic analyzer and its offline HTML report in `samples/`.

The future implementation will use React, TypeScript and Vite against versioned FastAPI responses. Build the main Workbench with application identity, inferred current architecture, transparent readiness bars, an evidence drawer, a risk register and a proposed roadmap. Keep current observations separate from target proposals.

Design tokens: graphite `#12110f`, charcoal `#211f1b`, ivory `#f3efe7`, secondary text `#b7b0a5`, copper `#d39a45`, readable sage and brick severity variants. No blue primary colour. Use compact navigation, thin borders, 4–8px radii, keyboard focus, reduced motion and text-labelled severity. Every visible control must work against real assessment data. Do not add fake login, export, approval or upload buttons.

Create components and features only as they are implemented. Persistence/API contracts should be stable before UI integration. See `docs/00_PRODUCT_AND_ARCHITECTURE.md`.
