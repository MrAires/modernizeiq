# ModernizeIQ — editorial edition

Ivory background, plum accents, horizontal navigation, large serif titles and readable sans-serif body text distinguish this report from OpsPilot. Titles scale from 36–56px; section headings are 27px; ordinary report text is 14–17px.

Quick preview: open samples/legacy-assessment/assessment.html.

Existing installation: replace backend/app/services/report.css with this version, then run RUN_DEMO.bat to regenerate your report. Refresh the browser. Newly generated reports inherit the new theme.

This is a completed design update to the deterministic milestone; future API/React/AI features are not added by this update.
